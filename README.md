# Map Manager

Tools for custom maps in CarX Drift Racing Online 2. First feature: custom maps get a schematic preview instead of the green one.

**Requires the [Compatibility Layer](https://github.com/david568303/Dro2-compatibility-layer/releases/tag/0.1-alpha)** (install it first).

## Install

1. Install the [Compatibility Layer](https://github.com/david568303/Dro2-compatibility-layer/releases/tag/0.1-alpha).
2. Download `MapManager.zip` from the [0.1-alpha release](https://github.com/david568303/map-manager/releases/tag/0.1-alpha).
3. Extract it into `<game folder>\BepInEx\plugins`.
4. Launch the game.

To turn the fix off, set `Enabled = false` in `BepInEx\config\carx.mapmanager.cfg`.

More details: [docs/DETAILS.md](docs/DETAILS.md)
